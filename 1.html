Cloud Sync Setup

Connect to Firebase Firestore to sync data to the cloud. Only administrators can configure this.

How to Get Your Firebase Config (5 min, free)
  1. Go to console.firebase.google.com
  2. Click Create a project → name it (e.g. "MankiTawaData")
  3. Disable Google Analytics (not needed) → Create project
  4. Click the Web icon (</>) to register a web app
  5. Give it a nickname → Register app
  6. Copy the firebaseConfig values below
  7. Go to Build → Firestore Database → Create database
  8. Choose Start in test mode → Select region → Done
  9. Go to Authentication → Sign-in method → Enable Anonymous → Save

⚠️ Important: After 30 days, test mode expires. Set Firestore security rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
